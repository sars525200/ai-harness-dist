# 專案工作規則（探針環境）

本檔存在的唯一目的：**讓 hook 注入的訊息有一個可核對的來源。**

2026-07-30 實測發現，模型拒絕採信 hook 訊息的首要理由是「我載入的 CLAUDE.md 裡
沒有這條規則」——那是隔離環境的固有缺陷，不是措辭問題。少了這份檔案，探針會
量到假陰性（訊息其實到得了，但被判為不可信而不採用），從而誤判「通道不通」。

刪掉這個檔案會讓探針失去可信度變因的控制。**要測「來源不可核對時會怎樣」，
請改成暫時重命名，測完改回來。**

## §9 部署環境與存取【硬規則】

- ops timer 腳本（`backup_db.sh`、`health_check.py`）的實際執行路徑是

  必須另外 `scp` 過去並手動驗證一次。已咬過 2 次。
