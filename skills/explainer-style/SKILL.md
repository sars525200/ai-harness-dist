# 說明頁樣式對照表

> **數值全部在同目錄的 `tokens.csv`，這裡只放判斷與禁令。**
> 兩邊各留一份必然漂移。
>
> **這份存在的理由**：每次做說明頁都重新挑一次顏色與字級，結果每頁長得都不一樣。
> 表的用途是**消除「挑選」這個動作**——查表拿值，查不到就停下來問。

## 怎麼查（派出去的角色也照這個走）

| 要找什麼 | CSV 的哪裡 |
|---|---|
| 顏色 | `kind=token` → `light`／`dark` 欄，`usage` 欄講用途 |
| 字級（六階） | `kind=type` → `light` 欄，`note` 欄有 weight 與行高 |
| 圓角 / 版面尺寸 | `kind=radius` / `kind=layout` |
| 字體堆疊 | `kind=font` → 直接整串複製 |
| 元件規格（提示框五級、徽章、表格） | `kind=component` → `token` 欄指向要用的色 |

一行查法（`tokens.csv` 在**本 skill 載入時印出的 base directory** 底下；
這台機器解析後是 `~/.claude/skills/explainer-style/tokens.csv`）：

```
grep -i "danger" ~/.claude/skills/explainer-style/tokens.csv
```

## 查表流程（三步）

1. **先問「這是什麼意思」**，不是「這裡要什麼顏色」——危險？次要？框線？已完成？
2. **從語意那一列取變數名**，不要把色碼抄進元件。
3. **表上沒有就停**。不准調一個相近值——每調一次，色表就多一種，浮動就是這樣來的。

## 三段式主題定義（缺一段就有一種設定會壞）

```css
/* 1. 淺色：完整定義在裸 :root —— 系統設「跟隨」的人吃這一段 */
:root { --canvas:#ffffff; --fg:#1f2328; /* …全部 token… */ }

/* 2. 系統深色，且使用者沒明確選淺色 */
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) { --canvas:#0d1117; --fg:#e6edf3; }
}

/* 3. 明確選深色，蓋過淺色系統 —— 少這段，切換鈕按了沒反應 */
:root[data-theme="dark"] { --canvas:#0d1117; --fg:#e6edf3; }
```

## 硬規則

- **必須**：色票三段式定義齊全。缺任何一段，就有一種系統設定會看到讀不了的頁。
- **必須**：`body` 背景明確指定 `var(--canvas)`，不留空——留空會借用外層底色，變成深底深字。
- **必須**：寬的東西（表格、程式碼、圖）自己橫向捲，整頁不准橫捲。
- **建議**：字級只用 CSV 上那六階；狀態同時用顏色和形狀；技術細節收進獨立區塊。
- **禁止**：元件裡直接寫死顏色值——換主題時那一塊不會跟著換。
- **禁止**：用表情符號當章節標記。
- **禁止**：引用外部圖片、字型檔、程式庫（Google Fonts 除外）——發布後那些請求全被擋掉，
  頁面少東西且**不會報錯**。

## 為什麼不准自己調（業界依據，2026-08-28 查證）

- **顏色分三層、只能往下引用**：原始值 → 語意名 → 元件專用名。元件直接抓原始色值，整套換色時必漏。
- **AI 生成介面有三個固定毛病**：捏造不存在的名稱、同一次工作中數值漂移、換一則對話忘掉脈絡。
  對策是把清單做成**封閉的**——表上有的才准用，沒有的必須回頭問，而不是給「參考範例」自由發揮。
- **規範要能被自動檢查**。沒有檢查的規範只在有人記得的時候生效。
