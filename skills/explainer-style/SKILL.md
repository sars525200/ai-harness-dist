# 說明頁樣式對照表

> **這份存在的理由**：每次做說明頁都重新挑一次顏色與字級，結果每頁長得都不一樣。
> 對照表的用途是**消除挑選這個動作**——查表拿值，查不到就停下來問，不自己調一個相近的。
>
> 對應樣本頁（同時是規範也是範例）：`.scratch/explainer-style-guide.html`

---

## 查表流程（三步）

1. **先問「這是什麼意思」**，不是「這裡要什麼顏色」——危險？次要？框線？已完成？
2. **從語意欄找到那一列**，取對應的變數名，不要抄色碼進元件。
3. **表上沒有就停**。不准調一個相近值——每調一次，色表就多一種，浮動就是這樣來的。

## 色票（GitHub Primer）

淺色定義在裸 `:root`，深色兩份（系統偏好 + 明確選擇）。

| 語意 | 變數 | 淺色 | 深色 | 用在哪 |
|---|---|---|---|---|
| 底色 | `--canvas` | `#ffffff` | `#0d1117` | 頁面背景 |
| 次層底 | `--canvas-subtle` | `#f6f8fa` | `#161b22` | 卡片、程式碼區塊、表頭 |
| 框線 | `--border` | `#d1d9e0` | `#30363d` | 卡片框、分隔線 |
| 淡框線 | `--border-muted` | `#d8dee4` | `#21262d` | 表格列線、標題底線 |
| 正文 | `--fg` | `#1f2328` | `#e6edf3` | 標題與內文 |
| 次要文字 | `--fg-muted` | `#59636e` | `#8b949e` | 說明、表頭文字 |
| 更淡文字 | `--fg-subtle` | `#6e7781` | `#6e7681` | 圖說、標籤、註腳 |
| 主色 | `--accent` | `#0969da` | `#4493f8` | 連結、資訊提示 |
| 成功 | `--success` | `#1a7f37` | `#3fb950` | 通過、已完成 |
| 注意 | `--attention` | `#9a6700` | `#d29922` | 待驗、有前提 |
| 危險 | `--danger` | `#cf222e` | `#f85149` | 失敗、不可逆、硬規則 |
| 已處理 | `--done` | `#8250df` | `#a371f7` | 已關閉、已歸檔 |

輔助值：`--neutral-soft` 淺 `rgba(129,139,152,.12)` / 深 `rgba(110,118,129,.20)`（行內 code 底、斑馬紋）。

## 排版尺度

| 項目 | 值 | 備註 |
|---|---|---|
| 字級（六階，只准用這些） | `32 / 24 / 20 / 16 / 13 / 12` px | 大標 / 章節 / 小節 / 正文 / 補充 / 標籤 |
| 行高 | `1.5` | 中文比英文密，不低於此 |
| 圓角 | `6px` | 大容器 12px、膠囊 999px，其餘一律 6px |
| 頁寬 | `1012px` | 寬表可放寬到 1100px |
| 正文行寬 | `68ch` | 超過就換行 |
| 區塊間距 | `40px` / `16px` | 章節之間 / 章節內 |
| 正文字體 | `-apple-system, BlinkMacSystemFont, "Segoe UI", "Noto Sans TC", "Microsoft JhengHei", Helvetica, Arial, sans-serif` | 英數走系統字，中文走思源黑體 |
| 等寬字體 | `ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, "Liberation Mono", monospace` | 路徑、指令、色碼、版號 |

Google Fonts 是 Artifact 唯一允許的外部來源，載 `Noto+Sans+TC:wght@400;500;700`。

## 三段式主題定義（缺一段就有一種設定會壞）

```css
/* 1. 淺色：完整定義在裸 :root —— 系統設「跟隨」的人吃這一段 */
:root { --canvas:#ffffff; --fg:#1f2328; /* …全部 token… */ }

/* 2. 系統深色，且使用者沒明確選淺色 */
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) { --canvas:#0d1117; --fg:#e6edf3; }
}

/* 3. 明確選深色，蓋過淺色系統 —— 少這段，切換鈕按了沒反應 */
:root[data-theme="dark"] { --canvas:#0d1117; --fg:#e6edf3; }
```

`body` 必須明確指定 `background: var(--canvas)`。留空會借用外層底色，變成深底深字。

## 元件

| 元件 | 規格 |
|---|---|
| 提示框 | 五級：背景說明（主色）／可以這樣做（成功）／非知不可（已處理紫）／注意（注意色）／會弄壞東西（危險）。左側 4px 色條 + 標題帶圖示 |
| 狀態徽章 | 膠囊 + 前置圓點，**顏色與形狀雙重編碼**，色弱與黑白列印都要分得出 |
| 表格 | 表頭吃次層底、12px 大寫字距、偶數列斑馬紋；數字欄 `tabular-nums` 靠右 |
| 程式碼區塊 | 次層底 + 淡框線 + 6px 圓角 + 16px 內距，字級 13px |
| 技術細節 | 收進獨立區塊，正文維持產品語言 |

## 硬規則

- **必須**：色票三段式定義齊全。缺任何一段，就有一種系統設定會看到讀不了的頁。
- **必須**：`body` 背景明確指定，不留空。
- **必須**：寬的東西（表格、程式碼、圖）自己橫向捲，整頁不准橫捲。
- **建議**：字級只用那六階；狀態同時用顏色和形狀；技術細節收進獨立區塊。
- **禁止**：元件裡直接寫死顏色值——換主題時那一塊不會跟著換。
- **禁止**：用表情符號當章節標記。
- **禁止**：引用外部圖片、字型檔、程式庫（Google Fonts 除外）——發布後那些請求全被擋掉，頁面少東西且不會報錯。
